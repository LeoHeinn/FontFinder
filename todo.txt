create env file
Open it and add your key (no quotes, no spaces around =):
GEMINI_API_KEY=your_actual_key_here
Add it to .gitignore so it never gets committed:
bash
echo ".env" >> .gitignore

If .gitignore doesn't exist yet, this creates it. If it does, this just appends the line.

Install python-dotenv so your script can read it:
bash
pip3 install python-dotenv
Update your script to load it instead of hardcoding the key:
python
import os
import base64
import requests
from dotenv import load_dotenv

load_dotenv()

API_KEY = os.environ.get("GEMINI_API_KEY")
